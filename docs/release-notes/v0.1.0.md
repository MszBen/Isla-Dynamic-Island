# Isla 0.1.0 🏝️ — the first release

A little dynamic island for Windows 11 that sits at the top of your screen: music with lyrics, a focus timer, a file shelf, and a way to watch and approve [Claude Code](https://claude.com/claude-code) without switching windows.

![Isla in action](https://raw.githubusercontent.com/MszBen/Isla-Dynamic-Island/main/docs/assets/hero.gif)

## ⬇ Install

1. Download **`Isla.exe`** below.
2. Double-click it. No installer, no Python needed.
3. A short tour opens the first time. Hover over the island at the top of your screen.

> **"Windows protected your PC"?** Isla isn't code-signed yet, so Windows is cautious about it the first time.
> Click **More info → Run anyway**. The SHA-256 of the file is in `Isla.exe.sha256` if you want to check it.

## ✨ What's in 0.1.0

- 🎵 **Music** from Spotify, your browser and other media apps, with play/pause/skip/seek and **synced lyrics** (click a line to jump to it)
- 🍅 **Focus timer** (Pomodoro) in the island, with a chime, adjustable length (− / + or the mouse wheel) and a **Break** button that pauses focus and resumes it afterwards
- 📥 **File shelf**: drop files on the island, drag them out into any app later
- 🤖 **Claude Code**: see what it's doing, **how many minutes it's been going and how many tokens it has used**; the island turns Claude orange while it works
- ✅ **Approve from the island**: *Deny / Allow always / Allow once* (the default). Answer in the terminal instead and the request clears from the island
- 🔌 **Charger and headphone animations**, 🎉 **confetti** when Claude or a focus session finishes, and a **mascot** with moods
- 👻 **Double-click** to make it see-through and click-through until you move away
- 🎮 Hides for fullscreen games and videos
- ⚙️ A separate **settings window**, a first-run **tour**, hover hints, and a right-click menu
- 🔒 No account, no telemetry. Everything stays on your PC (only lyrics are looked up online)

## 🔌 Connecting Claude Code

Open the **Agents** tab on the island and press **Connect**, then restart any Claude Code sessions that were already open. Isla backs up `~/.claude/settings.json` first and leaves your own hooks alone. If Isla isn't running, Claude Code isn't affected at all.

## 📝 Good to know

- Windows 10/11, 64-bit. Built and tested on Windows 11.
- This is a first release, so rough edges are likely. If something misbehaves, please [open an issue](https://github.com/MszBen/Isla-Dynamic-Island/issues) and attach `%APPDATA%\Isla\isla.log` if it exists.
- Not every song has synced lyrics on [lrclib.net](https://lrclib.net).
- Claude Code support currently covers Claude Code only (no Codex yet).
