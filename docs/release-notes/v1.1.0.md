# Isla 1.1.0 📋 — a clipboard tab, grouped shelf and multi-monitor support

## ⬇ Install

1. Download **`Isla.exe`** below.
2. Double-click it. No installer, no Python needed.

> **"Windows protected your PC"?** Isla isn't code-signed yet, so Windows is cautious about it the first time.
> Click **More info → Run anyway**. The SHA-256 of the file is in `Isla.exe.sha256` if you want to check it.

Already have Isla? Quit it from the tray icon, then replace the old `Isla.exe` with this one. Your shelf and settings are kept.

## ✨ What's new

- 📋 **Clips tab**: Isla remembers what you copy and you can **search** it. Click a clip to copy it again. It also shows your Windows clipboard history (Win+V) if that's turned on, and ignores copies from password managers. Clips live in memory only and are gone when Isla quits.
- 📥 **Grouped shelf**: files you drop together stay together. Drag the whole group out, **Ctrl+click** to pick several items (even from different groups) and drag them at once, or drag just one.
- 🖥️ **Choose your display**: if you have more than one screen, **Settings → Display** lets you pick where the island lives.
- ⚙️ **Settings cog** on the island, and while Settings is open the mascot gets her head opened up and worked on by a pair of robot arms.
- 🕐 The island waits a little longer before closing on the Shelf tab, so it's easier to carry files in and out.
- 🛠️ Project names on the Agents tab are no longer cut off when there's room for them.

## 📝 Good to know

- Windows 10/11, 64-bit. Built and tested on Windows 11.
- If something misbehaves, please [open an issue](https://github.com/MszBen/Isla-Dynamic-Island/issues) and attach `%APPDATA%\Isla\isla.log` if it exists.
